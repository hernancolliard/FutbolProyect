# Guia para afiliados de FutbolProyect

Bienvenido al programa de afiliados de FutbolProyect.

Esta guia explica como usar tu enlace, como se registran tus referidos y como se generan tus comisiones.

## 1. Tu enlace de afiliado

Vas a recibir un enlace personal como este:

```text
https://www.futbolproyect.com/r/tu-codigo
```

Ese enlace identifica los registros que llegan por tu recomendacion.

Ejemplo:

```text
https://www.futbolproyect.com/r/juanperez
```

## 2. Donde compartirlo

Podes compartir tu enlace en:

- Instagram.
- TikTok.
- YouTube.
- WhatsApp.
- Telegram.
- Email.
- Blogs.
- Comunidades de futbol.
- Grupos de jugadores.
- Grupos de entrenadores.
- Clubes.
- Agencias.
- Scouts y representantes.

## 3. Como funciona

1. Una persona entra a FutbolProyect usando tu enlace.
2. El sistema registra la visita.
3. Si esa persona se registra, queda asociada a tu cuenta de afiliado.
4. Si luego compra una suscripcion, se genera una comision para vos.

Importante: la comision se genera solamente cuando el pago fue confirmado.

## 4. Que pasa si la persona no se registra en el momento

El sistema guarda una cookie de atribucion por un periodo definido por FutbolProyect.

Si la persona vuelve y se registra dentro de ese periodo, el registro puede quedar asociado a tu enlace.

## 5. Que pasa si la persona entra despues por otro afiliado

Cada usuario puede tener un solo afiliado asociado.

Una vez que el usuario se registra, la atribucion queda fija. Otro enlace posterior no reemplaza tu atribucion.

## 6. Panel del afiliado

Si tenes una cuenta asociada como afiliado, podes entrar a:

```text
https://www.futbolproyect.com/afiliados/dashboard
```

En tu panel vas a ver:

- Tu nombre de afiliado.
- Tu codigo.
- Tu enlace para compartir.
- Clics.
- Registros.
- Suscriptores pagos.
- Ingresos generados.
- Comision pendiente.
- Saldo disponible.
- Total cobrado.
- Historial de comisiones.
- Historial de pagos.

## 7. Datos que no vas a ver

Por privacidad, no vas a ver datos personales de los usuarios referidos.

No se muestran:

- Emails.
- Telefonos.
- Direcciones.
- IDs completos de transacciones.
- Datos privados de suscriptores.

Los usuarios pueden aparecer anonimizados, por ejemplo:

```text
Usuario #A39F
```

## 8. Estados de tus comisiones

```text
PENDING
```

La comision fue generada, pero todavia esta en periodo de revision o seguridad.

```text
APPROVED
```

La comision fue aprobada para pago.

```text
PAID
```

La comision ya fue pagada.

```text
REVERSED
```

La comision fue revertida porque el pago fue reembolsado o revertido.

```text
CANCELLED
```

La comision fue cancelada por revision administrativa.

## 9. Cuando se genera una comision

Una comision se genera cuando:

1. Un usuario llega por tu enlace.
2. Ese usuario se registra.
3. Ese usuario paga una suscripcion.
4. PayPal confirma el pago.

No se generan comisiones por:

- Clics solamente.
- Registros gratuitos.
- Pagos no confirmados.
- Pagos reembolsados.
- Autorreferidos.
- Usuarios no atribuidos a tu enlace.

## 10. Periodo de seguridad

Las comisiones quedan pendientes durante un periodo de seguridad.

Esto permite cubrir:

- Reembolsos.
- Reversiones.
- Pagos fallidos.
- Revisiones administrativas.

Cuando el periodo termina, FutbolProyect puede aprobar la comision para pago.

## 11. Como se pagan las comisiones

Los pagos se realizan manualmente.

FutbolProyect registrara el pago dentro del sistema para que puedas verlo en tu historial.

El metodo de pago puede variar segun lo acordado:

- PayPal manual.
- Transferencia bancaria.
- Mercado Pago.
- Otro metodo acordado.

## 12. Buenas practicas para promocionar

Recomendaciones:

- Compartir el enlace con una explicacion clara.
- Enfocarse en jugadores, entrenadores, clubes, scouts, agentes y analistas.
- Evitar spam.
- No prometer resultados que FutbolProyect no garantiza.
- No usar mensajes enganosos.
- No crear cuentas propias para generar comisiones.
- No usar datos falsos.

```text
Registrate desde mi enlace:
https://www.futbolproyect.com/r/tu-codigo
```

## 14. Reglas importantes

- Tu enlace es personal.
- No se permiten autorreferidos.
- No se pagan comisiones por registros gratuitos.
- Las comisiones dependen de pagos confirmados.
- Si un pago es reembolsado, la comision puede revertirse.
- FutbolProyect puede pausar o bloquear afiliados ante uso indebido.

## 15. Soporte

Si tenes dudas, contacta al equipo de FutbolProyect e indica:

- Tu nombre.
- Tu email de afiliado.
- Tu codigo de afiliado.
- La consulta concreta.
